# Contributing to SPC FlexC Card

## Development

```bash
npm run build
npm run check
git diff --check
```

## Alarm safety

Do not implement automatic retries of state-changing alarm actions.

## Source and distribution

Edit `src/ha-spc-flexc-card.js`, then run `npm run build`.
